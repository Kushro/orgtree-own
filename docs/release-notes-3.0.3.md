# Orgtree 3.0.3

- **Usage credits.** The usage panel now shows an account's extra usage
  credits as one line under its name (for example "credits: 62,036") when the
  provider reports a balance. A weekly limit at 100% beside a credit balance
  no longer looks like an exhausted account. Codex balances are never rounded
  up. Nothing is shown when the provider reports no balance.
- **Luna reserve setting moved.** The app-wide "prefer Luna reserve capacity first"
  default now lives in App settings > Runtime instead of Default org
  settings, because it applies live to every agent that has no setting of its
  own.

This update contains only these two changes on top of 3.0.2.
