# Orgtree 3.0.4

- **Tidier desk footer.** When an agent's desk has 8 or more jump cards, they
  fold into one button that shows how many there are and expands on click,
  like the inbox's listener row. Below 8 the footer looks as before.
- **Search in agent and team dockets.** The agent and team docket views now
  have the same search box as the main docket. It filters the items that view
  already shows.
- **Presentations open on the newest one.** Opening an agent's presentations
  now selects the most recent presentation, as the org gallery already does.
  Opening a specific document, or picking one yourself, still wins.

This update contains only these three changes on top of 3.0.3.
