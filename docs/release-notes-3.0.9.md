# Orgtree 3.0.9

- **The window can be dragged by its top bar again.** With an Attention
  desk pinned flush to the top of the canvas, the top bar above it stopped
  moving the window once the desk's content had scrolled. It works again,
  whether the window is maximized or not.
- **Neighbour hires land on the side you press, and the circle view reads
  left to right.** In the circle view, a partly filled ring's arc and the
  full ring now run counter-clockwise from the top, so they follow the same
  left-to-right order as the row view. Hiring a neighbour from either open
  end of the arc places the new agent on that side.
- **The far-zoom hire arrow no longer leaves a name showing.** Pressing an
  agent's hire arrow at far zoom and moving away no longer leaves the
  agent's name expanded on the card.

This update contains only these three changes on top of 3.0.8.
