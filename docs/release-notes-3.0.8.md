# Orgtree 3.0.8

- **Changing an agent's account while it is working no longer fails.**
  If you change the account of an agent that is in the middle of a turn,
  the settings dialog now saves and shows the change as queued: the current
  turn finishes on the old account and the new account applies from the
  next turn. Before, saving showed an error.

This update contains only this change on top of 3.0.7.
